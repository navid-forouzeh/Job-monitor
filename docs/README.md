# Victory International — Website

Komplette Website für **Victory International Ltd** (Kitzbühel) als eine einzige,
selbständige HTML-Datei: `index.html`. Alle Bilder und Schriften sind eingebettet —
kein Server, keine Abhängigkeiten, funktioniert offline.

## Seiten
Home · Collection (Shop mit Filtern) · Produktseiten (Gin, Rosé, Blanc, Rouge,
Gift Crate, Poncho mit 6 Farben) · Beverages (Bar-Buchung) · Jewelry (Commission) ·
Fashion · World (Galerie) · Contact · Warenkorb + Order-Request-Checkout (per E-Mail).

## Veröffentlichen (3 Wege)

**1. GitHub Pages (dieses Repo)**
Repo-Settings → Pages → Branch `claude/victory-international-site-ytddfg`, Ordner `/docs` → Save.
Live unter: `https://navid-forouzeh.github.io/Job-monitor/`

**2. Netlify Drop (eigene URL in 1 Minute)**
https://app.netlify.com/drop öffnen und die Datei `index.html` hineinziehen.
Ergebnis: `https://<name>.netlify.app` — Name frei wählbar, später eigene Domain
(z. B. `victory-international.com`) anbindbar.

**3. Eigene Domain (der "offizielle" Weg für den Verkauf)**
Domain kaufen (z. B. victory-international.com) → bei Netlify/Vercel/Cloudflare Pages
verbinden → `index.html` hochladen. Fertig.
